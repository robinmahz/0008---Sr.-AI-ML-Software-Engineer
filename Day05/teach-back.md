# Day 5 Teach-Back Scripts

These scripts are designed for the short videos to explain today's work.

---

## English Teach-Back Script

**Scene 1: Introduction**
"Hi everyone! Today is Day 5 of my AI Software Engineering journey. Yesterday, I built a FastAPI backend for text summarization. Today, I brought that logic to life with a Next.js user interface."

**Scene 2: The UI Features**
"I focused on four critical UI states: 
1. **Idle**: A clean, premium design using glassmorphism.
2. **Loading**: A smooth spinner that gives instant feedback when the AI is processing.
3. **Success**: A clear summary display with stats like the reduction percentage.
4. **Error**: Descriptive messages if something goes wrong, like empty input."

**Scene 3: Technical Implementation**
"I used Next.js for the frontend and connected it to my FastAPI backend via API. The design uses modern CSS with dark mode and vibrant gradients to give it that 'AI-native' feel."

**Scene 4: Conclusion**
"This project taught me that great AI features aren't just about the model—they're about how the user interacts with that model. Thanks for watching!"

**दृश्य २: मुख्य विशेषताहरू**
"मैले आजको UI मा चारवटा मुख्य कुराहरूमा ध्यान दिएको छु:
